# Stage 17 — read-only system audit framework

2026-10-05 operator boundary repair: Git and Graphify process probes are injected from the operator. The collector itself reads only registered source and protected inventories; it has no process or Graphify collector import. The existing Graphify status CLI supplies sanitized `--facts` through a fixed command. The operator resolves its own script and loader, never executable code from `--repo`, and strips credential/provider environment variables. Missing probes refuse collection. Exclusion counters expose credential/size/budget/link/unreadable coverage gaps without increasing bounds or claiming complete external-runtime coverage. The unchanged frozen action-firewall grader verifies this reduced import boundary.

The audit separates source presence, deterministic qualification and live/official/owner evidence in fifteen mandatory domains. The default collector proves only registered source presence and reads current Git/Graphify facts. It does not synthesize domain test or live PASS. Each domain's aggregate test/live check remains NOT_RUN until its full canonical subcheck scope has qualified evidence; a representative module or one passing smoke is insufficient.

Evidence is closed metadata: check/version/class/current full HEAD/time, registered source reference and digest, state/severity/finding code. No raw private bodies, credentials, arbitrary URLs, instructions or execution capabilities are accepted. Native proxies/accessors/hidden properties are refused. Old HEAD and expired proofs become STALE; owner statements cannot override technical failures. A passing previously known limitation requires review. Normalized metadata is not an attestation or authority grant.

Graph HEAD, needs_update, freshness and integrity are independent checks. PARTIAL extraction and PENDING semantic enrichment remain disclosed. Missing source, technical failure, graph corruption/staleness or protected state uncertainty blocks closure. Partial baseline, unknown machine state and absent bound owner review cannot close the foundation. All outcomes grant zero execution/financial authority. The actual foundation remains OPEN/BLOCKED until genuine qualification and final owner review.

The collector imports no execution/approval/daemon/provider service. Registered source hashes and protected inventories are its only local effects; fixed Git/Graphify reads live in the operator. It rechecks injected HEAD/branch/Graphify after collection. Repository runtime/authority/projects/memory/approval/revenue roots are inventoried before and after; changes are reported without blaming unrelated writers. Even a separately reported background change cannot become an unchanged-state PASS. External configured runtime roots are unqualified, not implicitly covered. Credentials, oversized media, links and unreadable roots produce incomplete scope; credential bodies are never read.

`node --import tsx scripts/ayas-system-audit.ts` emits a report to stdout. Optional `--output` is a new JSON file only in an existing caller-created `ayas-audit-output-*` TEMP directory; it never writes production audit state. No server route, UI, scheduled task or persistent service is installed.
